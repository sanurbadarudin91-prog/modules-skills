# Security Incident Triage

## Overview
Effective triage minimizes impact by classifying incidents and prioritizing response efforts.

## Workflow
1. **Classify**: Assign incident type (e.g., Phishing, Malware, ATO).
2. **Prioritize**: Rate impact (e.g., Safety, Financial, Data).
3. **Escalate**: Assign to response teams per playbook.

## Security Rules
- Follow pre-defined playbooks.
- Maintain meticulous audit logs of triage decisions.
- Coordinate with legal/compliance for PII exposure.
